# FlowPilot — ToDo

- [ ] A plataforma deve automatizar tarefas repetitivas, como organizar arquivos, processar dados e gerar relatórios, em uma interface web navegável.
- [ ] A interface deve ser majoritariamente roxa, usar tema escuro e corrigir os problemas de legibilidade e acabamento da imagem de referência.
- [ ] O dashboard deve mostrar automações ativas, execuções totais, taxa de sucesso e tempo economizado.
- [ ] O usuário deve conseguir criar uma automação, editar seus dados básicos e executá-la pela interface.
- [ ] O sistema deve registrar cada execução, seu status, duração, horário e automação associada.
- [ ] O sistema deve exibir o histórico de execuções com filtros de status e busca.
- [ ] O sistema deve mostrar erros de cada automação com etapa, mensagem, payload e orientação de correção.
- [ ] A solução deve usar Python, APIs, banco de dados e fila de tarefas em uma implementação autocontida.
- [ ] O projeto deve iniciar com um comando simples e ser entregue em arquivo `.zip` completo.
